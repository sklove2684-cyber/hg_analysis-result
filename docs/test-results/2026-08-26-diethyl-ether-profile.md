# 디에틸에테르 Excel 프로필 검증 결과

- 검증일: 2026-08-26
- PDF: `디에틸에테르 152,153@완료.pdf`
- Excel: `(디에틸에테르) 152,153.xlsx`
- 분석종류: `디에틸에테르`
- canonical material: `Diethyl ether`
- 기준 RT: `1.305 min`

## 실제 Excel 구조

- 시트: `검량선`, `LOD(area입력)`, `회수율`, `std`
- 양식 식별 헤더: `LOD(area입력)!E2 = Diethyl ether`
- STD Area: `LOD(area입력)!F4:F8`
- 회수율 Area: `회수율!B28:B36`
- 일반 시료 Area 열: `LOD(area입력)!F19:F122`
- 일반 시료 분석번호 열: `LOD(area입력)!A19:A122`
- 실제 분석번호: `262-152`(19행), `262-153`(20행)

Excel에는 STD0과 다섯 개의 비영점 검량 수준(STD1~STD5)이 있다. 실제 PDF의
STD1~STD6을 농도와 Area 순서로 대조한 결과, Excel의 다섯 입력 슬롯에는 PDF의
`STD1, STD2, STD4, STD5, STD6`이 대응한다. PDF STD2와 STD3은 같은 농도 수준이며,
뒤쪽에 다시 등장하는 STD2는 재확인용 부분 세트로 분류한다.

## 검증 결과

- 실제 PDF: 27페이지, 27 Sample, 44 Peak
- `Diethyl ether` Peak: 16개
- `UNKNOWN_MATERIAL`: 0개
- Excel 입력: 14개
- 입력 제외: 30개
- 검증 오류: 0개
- `EXCEL_PROFILE_NOT_REGISTERED`: 발생하지 않음
- 뒤쪽 재확인 STD2: `DUPLICATE_STD_SET` 제외
- 생성 결과: 구조 검증 성공, COM 강제 재계산 미사용
- 입력 셀: 모두 숫자형으로 기록됨
- 수식, 스타일, 병합, 차트/도형/미디어: 원본과 동일
- `(혼유) 601-690.xlsx` 선택: `TEMPLATE_PROFILE_MISMATCH`로 생성 차단

일반 시료 `152`, `153`은 Excel에서 각각 19행과 20행으로 정확히 식별된다. 이번
PDF의 해당 일반 시료에는 `Diethyl ether` 명명 Peak가 없고 CS2만 있으므로 F19/F20은
기존 `N.D`를 유지한다. 숫자 Sample Name과 Excel 분석번호의 매핑은 단위 테스트에서
`152 -> F19`, `153 -> F20`으로 별도 검증했다.

## 회귀 테스트

- 전체 단위 테스트 통과(외부 fixture 의존 테스트 제외, 환경 의존 테스트 9개 skip)

- 기존 혼유, 1컬럼혼유, 알콜2, MEK, G2, 이소아밀/n-프로필 아세테이트,
  셀로솔브, G3, 초산, ACN, 에틸렌글리콜, B.C 결과 수치 유지

## 주의사항

원본 Excel에는 메틸 n-아밀케톤 영역의 기존 `#REF!` 수식과 일반 입력 영역의 기존
값이 일부 포함돼 있다. 디에틸에테르 자동화는 해당 영역을 수정하지 않으며, 구조
검증에서 새 오류나 비승인 셀 변경이 없음을 확인했다.
