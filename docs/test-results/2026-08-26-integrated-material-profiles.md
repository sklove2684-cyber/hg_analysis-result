# 2026-08-26 통합 물질/Excel 프로필 실파일 검증

## 범위

- 공통 물질 alias 정규화 및 analysis type eligibility 분리
- PDF/분석종류 변경 시 이전 배치·미리보기·Excel 상태 초기화
- 현재 PDF의 선택된 STD에서 얻은 RT를 이용한 복수 Peak 선택
- DMF/DMA 및 스토다드솔벤트 특수 Peak 처리
- 신규 Excel 프로필 9종
- 기존 프로필 회귀

업무 PDF와 Excel 원본은 로컬에서 읽기 전용 fixture로 사용했으며 Git에는 포함하지 않았다.
결과 파일은 임시 폴더에 생성했다. 프로그램의 기본 생성 정책에 따라 Excel COM 강제
재계산은 성공 조건으로 사용하지 않았고, 수식은 Excel에서 열 때 다시 계산되도록 원본
계산 설정과 함께 보존했다.

## 공통 규칙 검증

- alias key: 앞뒤/중복 공백, 영문 대소문자, 점, 단순 하이픈 차이를 정규화한다.
  숫자와 쉼표는 보존하고, 서로 다른 canonical 물질의 normalized key 충돌은 오류로 막는다.
- 전역 canonical을 알지만 현재 분석종류 대상이 아니면
  `MATERIAL_NOT_SUPPORTED_FOR_ANALYSIS`로 비차단 제외한다.
- 전역 registry에도 없는 물질만 `UNKNOWN_MATERIAL`로 남겨 검토 완료를 막는다.
- G2의 사염화탄소와 초산의 formic acid는 알려진 비대상 물질로 제외된다.
- 분석종류 변경 시 기존 review batch, 저장 배치 선택, Excel 원본/결과 경로와 미리보기를
  초기화한다.
- 신규 일반 프로필은 A=`STD1,2,3,4,5`, B=`STD1,2,3,4,6` 공통 규칙을 사용한다.
- 현재 PDF에서 선택된 STD의 물질 RT를 사용하며, 일반 시료의 복수 동명 Peak 중 RT가
  가장 가까운 1개만 선택한다. Area 최댓값으로 대체하거나 합산하지 않는다.
