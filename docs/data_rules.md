# Data rules confirmed through PHASE 7

- `area_raw`는 0 이상의 정수이며 직접 덮어쓰지 않습니다.
- RT는 `Decimal`로 보관합니다.
- PDF Peak Table 전체 행 수는 잔 피크 때문에 고정 검증값으로 사용하지 않습니다.
- Excel 숨김 미사용 영역의 기존 `#REF!`는 그대로 보존합니다.
- 실제 사용 영역에 새로 발생한 `#REF!`는 Excel 출력 검증 오류입니다.
- 원본 PDF와 Excel은 수정하지 않습니다.
- 기간 폴더명은 연도 두 자리와 `상`/`하`를 결합합니다(예: `26상`, `26하`).
- UNC를 기본 경로로 사용하고 Z:는 연결 확인용 보조 경로로만 사용합니다.
- 작업장, 기간, 최종 저장 폴더를 자동 생성하지 않습니다.
- PDF의 전체 Peak 개수는 잔 피크에 따라 달라질 수 있으므로 합격 기준으로 사용하지 않습니다.
- Peak Table의 빈 물질명 행도 원문 Peak로 보존하고 `UNNAMED_PEAK`로 Excel에서 제외합니다.
- 미등록 물질은 자동으로 추정하지 않고 사용자가 표준 물질명을 확인할 때까지 DB 저장을 막습니다.
- DIBK Peak는 합산하지 않고 Sample 안에서 Peak 번호 순으로 `peak_group_no`를 부여합니다.
- DIBK Peak는 개수와 관계없이 DB에 모두 개별 보존합니다.
- Excel 출력 시 Sample별 DIBK를 적용 Area 내림차순으로 정렬하고 상위 2개만 두 입력 슬롯에 기록합니다.
- Area 동률은 Peak No. 오름차순, RT 오름차순으로 정렬 순서를 고정합니다.
- DIBK 3위 이하 Peak는 삭제하지 않고 `DIBK_AREA_NOT_TOP2` 사유로 Excel 입력에서만 제외합니다.
- DIBK Peak가 3개 이상이라는 이유만으로 Excel 생성을 중단하지 않습니다.
- Excel에는 원문 Peak 총개수가 아니라 미리보기에서 `MAPPED`로 확정된 Peak만 입력합니다.
- 승인 입력 셀이 기존 수식 셀이면 생성을 차단하며, 빈 XML 셀은 인접 대응 셀의 스타일을 보존해 숫자 셀로 만듭니다.
- 원본 XLSX는 절대 직접 저장하지 않고, 사전·사후 구조 검증을 모두 통과한 임시 복사본만 최종 결과로 승격합니다.
- 최종 결과 저장 전 Microsoft Excel 전체 재계산이 반드시 성공해야 합니다.
