# PHASE 5 Excel 템플릿 구조 분석 보고서

## 1. 분석 범위와 원칙

- 기준 파일: `TEST/(혼유) 틀.xlsx`
- 분석 방식: XLSX ZIP/XML 읽기 전용 분석
- 원본 Excel 수정: 없음
- Peak 총개수: 잔 피크 때문에 달라질 수 있으므로 Excel 매핑 기준으로 사용하지 않음
- 기존 `#REF!`: 사용자 결정에 따라 숨김·과거 영역으로 간주하고 이번 자동화 대상에서 제외
- 확정 전 임의 입력 주소 사용 금지: 이 보고서의 승인 후 PHASE 6에서 매핑 규칙으로 사용

## 3. 이름 정의·인쇄·화면 구성

- `최종결과` 자동필터: `A37:AM186`
- 인쇄 영역:
  - `검량선!A1:R94`
  - `area!A1:AA59`
  - `최종결과!A1:AL63`
  - `회수율!A2:V67`
  - `STD제조!A2:X16`
- 인쇄 제목: `area`는 A열과 35행, `최종결과`는 37행
- 모든 시트는 A4 가로 방향이다.
- 조건부 서식: `area` 16개, `최종결과` 1개. 데이터 유효성 검사는 없다.

## 5. STD 입력 후보

Excel에는 5개 검량점 입력칸이 있다.

| Excel 표준 | 농도 참조 | 원본 Area 입력 |
|---|---|---|
| std1 | `area!F4:R4` ← `STD제조!P` | `area!F15:Q15`, DIBK `Z15`, `AA15` |
| std2 | `area!F5:R5` ← `STD제조!Q` | `area!F16:Q16`, DIBK `Z16`, `AA16` |
| std3 | `area!F6:R6` ← `STD제조!R` | `area!F17:Q17`, DIBK `Z17`, `AA17` |
| std4 | `area!F7:R7` ← `STD제조!S` | `area!F18:Q18`, DIBK `Z18`, `AA18` |
| std5 | `area!F8:R8` ← `STD제조!T` | `area!F19:Q19`, DIBK `Z19`, `AA19` |

- 단일 피크 물질은 `F:Q`에 숫자를 쓴다.
- DIBK 원본 피크는 `Z`, `AA`에 각각 쓴다.
- `R15:R19`는 `Z+AA` 합산 수식이므로 수정하지 않는다.
- STD 방식 A: PDF STD1~5를 Excel std1~5에 배치한다.
- STD 방식 B: PDF STD1~4와 STD6을 Excel std1~5에 배치하며 PDF STD5는 출력에서 제외한다.

## 6. 회수율 입력 후보

- 원본 Area 행: `회수율!37:45`
  - 저1~저3: 37~39행
  - 중1~중3: 40~42행
  - 고1~고3: 43~45행
- 단일 피크 물질: `B37:M45`
- DIBK 원본 피크: 각 행의 `U`, `V`
- DIBK 합계: `N37:N45 = U+V`; 수식 보호
- 계산 결과: `B58:T66`
- 핵심 13개 물질 평균 회수율: `B67:N67`

`O:T`와 `W`의 과거 보조 영역은 자동 입력 대상에서 제외한다.

## 7. 작업자 시료 입력 후보

- 작업자 입력 행: `area!37:183`
- 최대 작업자 행 수: 147개
- 분석번호: `A37:A183`
- 사업장명: `B37:B183`
- 측정시간: `C37:C183`
- 유량: `D37:D183`
- 총유량: `E37:E183 = C*D`; 수식 보호
- 단일 피크 물질 원본 Area: `F37:Q183`
- DIBK 원본 피크: `Z37:AA183`
- DIBK 합계: `R37:R183 = Z+AA`; 수식 보호
- `area!36행`은 LOD/보조 계산용 특수 행으로 판단되므로 작업자 입력에서 제외한다.
- `최종결과!40:186`이 `area!37:183`을 순서대로 참조한다.

샘플 템플릿의 `A37:A183`은 비어 있다. 따라서 실제 출력 시에는 사용자가 선택한 작업용 원본 Excel에 이미 있는 분석번호의 마지막 숫자와 PDF 숫자 Sample Name을 비교해 유일하게 일치한 행만 사용한다. 0개 또는 2개 이상 일치하면 자동 보정하지 않고 생성을 중단한다.

## 8. DIBK 구조와 상위 Area 선택 규칙

템플릿이 제공하는 DIBK 원본 피크 슬롯은 Sample당 정확히 2개다.

| 구분 | 원본 슬롯 | 합계 수식 |
|---|---|---|
| STD | `area!Z15:AA19` | `area!R15:R19 = Z+AA` |
| 작업자 | `area!Z37:AA183` | `area!R37:R183 = Z+AA` |
| 회수율 | `회수율!U37:V45` | `회수율!N37:N45 = U+V` |

처리 규칙:

1. DIBK 피크는 DB에서 합산하지 않고 모두 개별 보존한다.
2. Excel 출력 시 같은 Sample의 DIBK 피크를 `적용 Area 내림차순`으로 정렬한다.
3. Area가 같으면 `Peak No. 오름차순`, 그다음 `RT 오름차순`으로 순서를 고정한다.
4. 정렬 결과 상위 2개만 선택한다. 1위는 첫 슬롯(`Z` 또는 `U`), 2위는 둘째 슬롯(`AA` 또는 `V`)에 입력한다.
5. 피크가 1개면 첫 슬롯에 입력하고 둘째 슬롯은 비운다.
6. 3개 이상이어도 Excel 생성을 중단하지 않는다. 3위 이하 피크는 DB에 그대로 보존하고 Excel 입력에서만 제외한다.
7. 3위 이하 피크의 제외 사유는 `DIBK_AREA_NOT_TOP2`로 기록한다.
8. 미리보기에는 전체 DIBK 피크와 Area 순위, 선택 여부, 목표 셀을 함께 표시한다.

샘플 PDF처럼 DIBK가 3개 이상인 Sample도 위 규칙으로 가장 큰 Area 2개를 자동 선택한다.

## 9. 수식 보호 영역

다음 영역은 숫자 입력 대상이 아니다.

- `area!F29:S29`, `T29:Y29`: INTERCEPT
- `area!F30:S30`, `T30:Y30`: SLOPE
- `area!F31:S31`, `T31:Y31`: CORREL
- `area!F32:S32`, `T32:Y32`: STEYX
- `area!G33:Y33`: LOD 계열
- `최종결과!G31:AM35`: intercept/slope/correlation/SE/LOD
- `최종결과!F39:AM186`: 농도·환산 결과 수식
- `회수율!B58:T67`: 회수율 계산과 평균
- `STD제조` 전체 수식 셀
- 44개 차트, drawing 관계, 병합, 행 높이, 열 너비, 스타일 ID, 이름 정의, 인쇄 설정, 조건부 서식

## 11. 구조 검증 기준

PHASE 7에서 원본과 결과를 비교할 때 다음 항목은 동일해야 한다.

- 시트 수·이름·순서·상태
- 입력 대상 이외의 수식 위치와 수식 문자열
- 차트 44개와 drawing 관계
- 병합 범위
- 이름 정의와 자동필터
- 행 높이·열 너비·숨김 상태
- 스타일 ID와 숫자 형식
- 조건부 서식
- 페이지 설정·인쇄 영역·인쇄 제목
- 이미지·도형 관계

허용되는 차이는 승인된 입력 셀의 숫자, 수식 계산 캐시, 재계산용 workbook 속성, Excel이 저장하며 추가하는 허용 메타데이터뿐이다.

## 12. PHASE 6 확정 매핑

사용자 승인과 DIBK 상위 Area 규칙 변경을 반영해 다음 기준으로 확정했다.

1. STD 입력: `area!F15:Q19`, DIBK `Z15:AA19`
2. 회수율 입력: `회수율!B37:M45`, DIBK `U37:V45`
3. 작업자 입력: 실제 원본 Excel의 `area!A37:A183` 분석번호로 행을 찾고 `F:Q`, DIBK `Z:AA`에 입력
4. DIBK는 Sample별 적용 Area 상위 2개만 입력하고, 3위 이하는 DB 보존 후 Excel 입력에서 제외
5. 작업자 행 매칭 불일치 시 Excel 생성 중단
